# Tryvo — Try. Learn. Own it.

The application lives here. Start with the [repository README](../../README.md) for the product story, screenshots, local setup, AI configuration, security notes and tests.

From the repository root, run:

```sh
python prototypes/tryvo/server.py --port 8765
```

Open http://127.0.0.1:8765/. Keep the private `.env.tryvo` at the repository root, outside this served folder. Only `.env.example` is published.
